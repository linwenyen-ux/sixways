# 戰情籤・六大策略

美股與台股六大策略每日戰情板的手機版（PWA），加上今日籤、抽籤與模擬倉。

- 這裡**只有產生後的靜態檔**。資料由本機 `sixways_app.py` 每日產出到 `data/` 與 `d/`，
  美股週二～六 11:00、台股週一～五 15:10（台北時間）各自更新自己的市場。
- `data/us.json`、`data/tw.json`：兩市場同一結構。`d/<市場>/<代號>.json`：逐項判定長文，點進詳情才抓。
- **伺服器端零持股**：持股、成本、觀察標的都存在使用者手機的 localStorage，不會進這個 repo。
- `.nojekyll`：要求 GitHub Pages 原樣輸出。

本工具僅陳述規則判定結果，不構成投資建議。
